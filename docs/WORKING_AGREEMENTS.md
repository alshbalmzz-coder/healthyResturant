# دليل العمل

## الاجتماعات

تعقد مراجعة أسبوعية موجزة بقيادة سلمى لعرض التقدم، المخاطر، والقرارات المطلوبة.

## تبني القرارات

تسجل كل قرار يحتاج موافقة الفريق في المهمة ذات الصلة، ويذكر صاحب القرار والسبب والخطوة التالية.

## قواعد الجودة

- سلامة الغذاء وجودة المكونات أولويتان.
- لا تعتمد وصفة نهائيًا قبل مراجعتها غذائيًا وتشغيلًا.
- تتبع الهوية البصرية مواضيع المشروع الأساسية دون إفراط.
- توثق كل تكلفة قبل اعتمادها في الميزانية.

## نتائج العمل المطلوبة

يضع كل عضو ناتجًا واضحًا قابلًا للمراجعة، مثل مستند، نموذج قرار، قائمة، وصفة، نموذج هوية، خطة حملة، قائمة موردين أو ميزانية.
