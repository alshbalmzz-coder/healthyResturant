# سجل المهام والمسؤوليات

## سلّم ما زالت متاحة للتخصيص

- [ ] اعتماد رؤية المشروع ومؤشرات النجاح.
- [ ] اعتماد مراحل المشروع وجدوله الزمني.
- [ ] اعتماد صياغة متطلبات قائمة الطعام.
- [ ] اعتماد هوية بصرية أولية.
- [ ] إعداد خطة تسويق ما قبل الإطلاق.
- [ ] تأهيل الموردين وخطة التشغيل.
- [ ] إعداد الميزانية الأساسية.

## أدوار البدء

- **سلمى:** توثيق الرؤية وخطة المتابعة.
- **يزن:** إعداد قائمة وصفات مبدئية للاختبار.
- **ليان:** وضع معايير القيمة الغذائية والتوازن.
- **رامي:** إعداد موجهات الاسم والشعار والهوية.
- **جود:** إعداد استراتيجية المحتوى والجمهور.
- **كنان:** إعداد قائمة الموردين ومتطلبات التشغيل.
- **نور:** إعداد الميزانية والتدفقات الأساسية.
